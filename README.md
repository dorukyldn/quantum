# Kuantum Tezgahı · Quantum Bench

Süperiletken qubit donanımını VNA, Smith abağı, spektrum analizörü ve osiloskop ekranlarında anlatan,
tarayıcıda çalışan iki dilli (TR/EN) eğitim portalı.

An interactive, bilingual (TR/EN) bench that explains superconducting qubit hardware on the screens
of RF instruments: VNA, Smith chart, spectrum analyser and oscilloscope.

**Canlı / Live:** https://dorukyldn.github.io/quantum/

Hazırlayan / Author: Doruk Yıldön
